# Loja Simples - Controle de Produtos 🛒

Projeto desenvolvido para a disciplina de Fundamentos Web do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla / Puro)

## 📌 Funcionalidades
- Cadastro de novos produtos com validação de quantidade.
- Listagem dinâmica dos produtos cadastrados.
- Edição de produtos existentes no próprio formulário.
- Remoção de produtos da lista.
- Contador de produtos e aviso automático de lista vazia.
- Layout responsivo com estrutura semântica.

## 🛠️ Como executar
Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador.
